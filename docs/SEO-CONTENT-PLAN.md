## 2. SERP Overlap Analysis

### Method
For each pair within an intent group, two Google searches were run. Shared top-10 organic URLs were counted. Thresholds applied:
- **7-10 shared URLs** → same post (merge)
- **4-6 shared URLs** → same cluster (spoke-to-spoke link)
- **2-3 shared URLs** → interlink only
- **0-1 shared URLs** → separate cluster
