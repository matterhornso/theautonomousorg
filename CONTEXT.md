## What We Do

The Autonomous is an AI-powered platform that enables companies to run their entire business with AI agents for every workflow. Unlike chatbots that answer questions and forget, our agents are autonomous workers — they research, execute, report back, remember everything, and get smarter over time.

**Key differentiators from chatbots:**
- **Persistent memory** — agents remember every conversation, decision, and context across sessions
- **Real tool integrations** — agents use actual APIs (Apollo.io, Instantly.ai, web search, CRMs, etc.)
- **Proactive execution** — agents identify tasks and act before being asked
- **Role specialization** — each agent has domain-specific skills and knowledge for its job
- **Inter-agent collaboration** — agents communicate with each other via @mentions, like a real team
- **Company context** — we research the customer's company (website, socials, news) and give every agent deep business context

## Technical Architecture

Each AI agent consists of four components:

1. **The Brain (LLM):** Claude Sonnet 4.6 by default — best-in-class reasoning. Users can bring their own model (GPT-4o, Gemini, Llama, Mistral, or any OpenAI-compatible endpoint).
2. **Memory:** Persistent storage that retains conversation history, company context, decisions, and lessons learned across all sessions.
3. **Tools:** Real API integrations — searching Apollo.io for prospects, sending emails via Instantly.ai, updating databases, browsing the web, and more.
4. **Skills:** Pre-configured workflows and domain knowledge specific to each agent's role.

**Infrastructure:**
- Each agent runs in its own isolated cloud instance with dedicated resources
- Data never crosses between companies
- All communications encrypted in transit and at rest
- Customer data is not used to train AI models
- Enterprise customers can access SOC2 and HIPAA compliance
